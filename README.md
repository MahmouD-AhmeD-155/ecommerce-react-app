# 🛒 E-commerce Store (Frontend)

A modern, high-performance E-commerce web application built with **React.js** and **Vite**.

## 🚀 Features
* **Dynamic Sliders:** Interactive product displays using **SwiperJS**.
* **Modern UI:** Clean icons and professional look with **React Icons**.
* **Product Catalog:** Browsing products with a modern grid layout.
* **Shopping Cart:** Functional cart logic with real-time updates.
* **Responsive Design:** Optimized for all screen sizes.

## 🛠️ Tech Stack
* **Framework:** React.js (Vite)
* **Sliding Components:** [Swiper.js](https://swiperjs.com/)
* **Icons:** [React Icons](https://react-icons.github.io/react-icons/)
* **Styling:** CSS3
